# pscp-69070096

Individual coursework submissions for **Problem Solving and Computer Programming** at the School of Information Technology, KMITL.

## Structure

Each problem is stored in a directory named using its iJudge problem ID:

```text
ojxxxx/
├── submission.py
└── main.py
```

- submission.py — submission details, planning, selected test cases, and related answers. 
- main.py — solution for the problem.
